# Security Policy · Politique de sécurité

## Reporting a vulnerability

**Do not open a public issue.** Report vulnerabilities privately through GitHub:
[Report a vulnerability](https://github.com/sputier/polymnia/security/advisories/new).

Please include the affected component, steps to reproduce and the impact you observed. You will get a first answer within 7 days. Once a fix is released, the advisory is published and you are credited if you wish.

## Supported versions

Polymnia is in early development. Only the latest commit on `main` receives security fixes.

---

## Signaler une faille

**N'ouvrez pas d'issue publique.** Signalez les failles en privé via GitHub :
[Signaler une faille](https://github.com/sputier/polymnia/security/advisories/new).

Indiquez le composant concerné, les étapes pour reproduire et l'impact constaté. Vous recevrez une première réponse sous 7 jours. Une fois le correctif publié, l'avis est rendu public et vous êtes crédité si vous le souhaitez.

## Versions prises en charge

Polymnia est en début de développement. Seul le dernier commit de `main` reçoit des correctifs de sécurité.
